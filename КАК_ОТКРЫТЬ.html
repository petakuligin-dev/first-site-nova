Почему index.html пустой?

Это современный сайт на React. Браузер не может показать его просто двойным кликом по index.html — нужен локальный сервер.

Самый простой способ:
Дважды нажмите файл ОТКРЫТЬ_САЙТ.bat в папке проекта.

Через терминал

  1. Установите Node.js (LTS), если ещё нет
  2. Откройте папку проекта в терминале
  3. Выполните: npm install
  4. Затем: npm run dev
  5. Откройте http://localhost:5173

Посмотреть на другом ПК в сети

После npm run dev в консоли появится строка Network с адресом вида http://192.168.x.x:5173 — откройте его на другом компьютере в той же Wi‑Fi сети.

Готовая сборка (без разработки)

Запустите СБОРКА_И_ПРОСМОТР.bat или npm run serve.
